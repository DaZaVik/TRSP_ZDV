# Adaptio — сервис адаптации новых сотрудников

Веб-приложение на Django для управления адаптацией (онбордингом) новых сотрудников: этапы, задачи, наставники, контроль прогресса.

Автор: Заботкин Данила Викторович, группа ЭФБО-17-24.

## Назначение

Первые недели на новом месте — самый уязвимый период: новичок не знает, что от него ждут, HR ведёт адаптацию в таблицах и чатах, а наставник узнаёт о проблемах, когда человек уже решил уволиться. Adaptio переводит этот процесс из головы HR в систему: план адаптации создаётся из шаблона, задачи разбиты по этапам и имеют дедлайны, прогресс виден всем участникам.

## Целевая аудитория

- **HR-специалист** — ведёт справочник этапов и шаблоны адаптации, заводит новичков, назначает планы и наставников, видит общую картину.
- **Наставник** — видит своих подопечных, их прогресс по этапам и просроченные задачи.
- **Новый сотрудник** — получает понятный чеклист по этапам с дедлайнами и материалами, отмечает выполненное.

Целевой сегмент — малый и средний бизнес, где нет корпоративной HRM-системы, а адаптация ведётся вручную.

## Предметная область

Адаптация — процесс ввода нового сотрудника в должность за ограниченный срок (обычно 1–3 месяца). Он делится на **этапы**: знакомство с компанией, обучение, первые рабочие задачи, подведение итогов. Внутри каждого этапа — конкретные **задачи**: получить доступы, изучить регламент, познакомиться с командой, выполнить первую задачу. Задачи привязаны ко дню выхода: «в первый день», «к концу первой недели».

За новичком закрепляется **наставник** — опытный сотрудник, который отвечает за его прогресс. HR оформляет типовой набор задач для должности как **шаблон**. При выходе сотрудника из шаблона создаётся **персональный план**: задачи копируются, дедлайны рассчитываются от даты выхода. Новичок выполняет задачи, наставник и HR следят за прогрессом и просрочками. Когда все задачи закрыты, план завершён.

## Основные сущности

Обязательные по заданию: **сотрудник, задача, этап, наставник**.

| Сущность | Что это | Связи |
|---|---|---|
| **Сотрудник** (Employee) | Профиль пользователя: отдел, должность, дата выхода | → пользователь системы, отдел; ← планы, наставник |
| **Наставник** (Mentor) | Сотрудник, закреплённый за новичками: специализация, статус активности | → сотрудник; ← планы |
| **Этап** (Stage) | Фаза адаптации с порядком следования и описанием | ← задачи |
| **Задача** (Task) | Конкретная задача новичка: этап, дедлайн, материал, статус выполнения | → план, этап |
| Отдел (Department) | Подразделение компании | ← сотрудники, шаблоны |
| Шаблон адаптации (OnboardingTemplate) | Типовой набор задач для должности | → отдел; ← задачи шаблона |
| Задача шаблона (TemplateTask) | Заготовка задачи: этап, срок «N дней от выхода» | → шаблон, этап |
| План адаптации (OnboardingPlan) | Персональный план новичка: дата выхода, наставник, статус | → сотрудник, наставник, шаблон; ← задачи |

Ключевое разделение: **шаблон** — чертёж, **план** — конкретный экземпляр. Изменение шаблона не затрагивает уже назначенные планы.

## Основные функции

**HR**
- Ведение справочника этапов адаптации
- Создание и редактирование шаблонов и их задач
- Заведение новых сотрудников, назначение наставников
- Назначение плана из шаблона с автоматическим расчётом дедлайнов
- Список всех новичков с прогрессом и статусом

**Новый сотрудник**
- Личный чеклист задач, сгруппированный по этапам, с дедлайнами и материалами
- Отметка задач выполненными
- Прогресс по плану и по каждому этапу

**Наставник**
- Список подопечных с прогрессом
- Подсветка просроченных задач

**Общее**
- Авторизация и разграничение доступа (HR / наставник / новичок)
- Административная панель для управления справочниками

## Стек

Python 3.12+, Django 5, SQLite, Django Templates + Bootstrap 5.

## План развития

**v1 (текущая)** — этапы, шаблоны, планы, чеклист, наставники, роли, прогресс, просрочки.

**v2**
- Email-уведомления о новых задачах и просрочках
- Комментарии к задачам (диалог новичка и наставника)
- Материалы в виде файлов, а не только ссылок

**v3**
- Аналитика для HR: среднее время адаптации, типовые точки застревания по этапам
- Опросы обратной связи новичка по итогам адаптации
- Telegram-бот для уведомлений
- REST API для интеграции с внешними HR-системами
